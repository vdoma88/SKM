# Направление разработки (`ROADMAP.md`)

Поэтапный план развития приложения от рабочего MVP до полноценной цеховой инженерной платформы.

## Этап 1. Фундамент данных и MVP (Выполнено в текущем репозитории)
- [x] Реляционная схема PostgreSQL (`db/schema.sql`) под ISO 13399, ISO 1832 и ISO 513.
- [x] Бренд-нейтральный стартовый набор данных (`db/seed.sql`) для точения, фрезерования и корпусного сверления.
- [x] Парсер кодов ISO 1832 с генерацией ключа посадочного гнезда (`app/iso1832.py`).
- [x] Физическое ядро Кинцле с учётом утонения стружки и лимитов станка (`app/kienzle.py`).
- [x] FastAPI-сервис (`/api/select`, `/api/calculate`, `/api/iso1832/parse`).
- [x] Интерактивный GUI-прототип (`static/index.html`) с картой стружколома, профилями станков и офлайн-движком.

## Этап 2. Подключение PostgreSQL и расширение каталога (Выполнено)
- [x] Реализован PostgreSQL-адаптер в `app/repository.py` (psycopg3) поверх `v_insert_selector_catalog`.
- [x] База `db/seed.sql` расширена до 17 пластин (`WNMG`, `DNMG`, `VNMG`, `SNMG`, `DCMT`, `CNGA`, `SEKT`, `RDMT`, `SPMG`) и 13 корпусов.
- [x] Добавлен модуль поиска аналогов (Cross-Reference Engine, `GET /api/inserts/{id}/equivalents`).
- [x] Добавлен расчёт шероховатости поверхности ($R_a \approx \frac{f_n^2}{32 \cdot r_\varepsilon}$) и прогиба расточных оправок по балочной модели ($L/D$).

## Этап 3. Инженерный интерфейс нового поколения (React + 3D)
- [ ] Перенос GUI на React + TypeScript + Tailwind + shadcn/ui с сохранением офлайн-движка.
- [x] Интегрирован 3D-просмотрщик параметрической геометрии ISO 1832 (`app/geometry3d.py`, экспорт STL) и CAD-моделей STEP/IGES/BREP/STL в браузере (`Three.js` + `occt-import-js` WASM + офлайн Canvas-фолбэк).
- [x] Реализован режим сравнения до 3 пластин «бок о бок» (экономика на кромку, MRR, мощность, Ra, подсветка лучших показателей).
- [x] Добавлено сохранение наладок и пользовательских профилей станков, экспорт в CSV (Excel), JSON, FreeCAD `.fctb` и печать карты наладки.

## Этап 4. Цеховая автономность и CAM-интеграция
- [ ] Упаковка в нативное офлайн-приложение на **Tauri (Rust)** + локальный снапшот SQLite.
- [x] Реализован экспорт сборок в **ISO 13399 GTC v2.0**, **Autodesk Fusion 360 (`.tools`)**, **FreeCAD (`.fctb`)**, Excel CSV и печать PDF.
- [x] Реализован модуль **«Склад цеха»** (`app/inventory.py`, вкладка в GUI) с импортом/экспортом CSV, учётом реальных цен, фильтром «только в наличии» и расчётом экономики по Тейлору (`app/economics.py`).
- [x] Проработка осевого инструмента (v1.1): U-свёрла СМП, сменные твердосплавные коронки и монолитные ЦТ-свёрла с расчётом осевого усилия $F_f$, давления СОЖ (бар), $L/D_c$, циклов ЧПУ (`G81`/`G73`/пилот 2xD) и 3D-геометрией свёрл.

## Этап 5. Цеховая платформа полного цикла (Выполнено в SKM v2.0)
- [x] Реальная кривая мощности и крутящего момента шпинделя $P(n)/M(n)$ с интерактивным графиком и проверкой лимитов в точке рабочих RPM.
- [x] Модуль резьбонарезания (`app/threading.py`): 32 стандарта M/MF/G/NPT, режущие метчики, бесстружечные раскатники и ЦТ-резьбофрезы с компенсацией осевой подачи.
- [x] Модуль чистовой обработки отверстий ISO 286 (`H7/H8/IT6`): ЦТ-развёртки и микрометрические расточные головки с расчётом припуска и $R_a$.
- [x] Генератор ЧПУ G-кода (`app/gcode.py`) под стойки **Fanuc / Haas** и **Siemens Sinumerik 840D** с выгрузкой `.nc`.

## Этап 6. Коммерческая витрина продаж и заказов (Выполнено в SKM v2.1)
- [x] Главный экран переориентирован в инструмент продажи и заказа (`🛒 Подбор и заказ`) с умным поиском по коду, державке и материалу клиента.
- [x] Коммерческие карточки с ценой за шт / упаковку / режущую кромку, остатками, аналогами и апселлом совместимых корпусов (`app/sales.py`).
- [x] Корзина заказа и генератор КП (скидки, НДС 20%, печать/PDF, текст для Telegram/WhatsApp, Excel CSV и история заказов).
- [x] Все технические инструменты (декодер ISO 1832, Кинцле, кривая шпинделя, резьба/G-код, 3D, CAM) вынесены в отдельную группу вкладок «Для технолога».
