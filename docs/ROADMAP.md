# Направление разработки (`ROADMAP.md`)

Поэтапный план развития приложения от рабочего MVP до полноценной цеховой инженерной платформы.

## Этап 1. Фундамент данных и MVP (Выполнено в текущем репозитории)
- [x] Реляционная схема PostgreSQL (`db/schema.sql`) под ISO 13399, ISO 1832 и ISO 513.
- [x] Бренд-нейтральный стартовый набор данных (`db/seed.sql`) для точения, фрезерования и корпусного сверления.
- [x] Парсер кодов ISO 1832 с генерацией ключа посадочного гнезда (`app/iso1832.py`).
- [x] Физическое ядро Кинцле с учётом утонения стружки и лимитов станка (`app/kienzle.py`).
- [x] FastAPI-сервис (`/api/select`, `/api/calculate`, `/api/iso1832/parse`).
- [x] Интерактивный GUI-прототип (`static/index.html`) с картой стружколома, профилями станков и офлайн-движком.

## Этап 2. Подключение PostgreSQL и расширение каталога (Выполнено)
- [x] Реализован PostgreSQL-адаптер в `app/repository.py` (psycopg3) поверх `v_insert_selector_catalog`.
- [x] База `db/seed.sql` расширена до 17 пластин (`WNMG`, `DNMG`, `VNMG`, `SNMG`, `DCMT`, `CNGA`, `SEKT`, `RDMT`, `SPMG`) и 13 корпусов.
- [x] Добавлен модуль поиска аналогов (Cross-Reference Engine, `GET /api/inserts/{id}/equivalents`).
- [x] Добавлен расчёт шероховатости поверхности ($R_a \approx \frac{f_n^2}{32 \cdot r_\varepsilon}$) и прогиба расточных оправок по балочной модели ($L/D$).

## Этап 3. Инженерный интерфейс нового поколения (React + 3D)
- [ ] Перенос GUI на React + TypeScript + Tailwind + shadcn/ui с сохранением офлайн-движка.
- [ ] Интеграция 3D-просмотрщика STEP/IGES моделей пластин и сборок через `Three.js` + `occt-import-js` (WebAssembly).
- [ ] Режим сравнения 2–3 пластин «бок о бок» (экономика на кромку, машинное время, нагрузка на шпиндель).
- [ ] Сохранение пользовательских наладок (`user_tool_assemblies`) и профилей станков с кривыми момента/мощности.

## Этап 4. Цеховая автономность и CAM-интеграция
- [ ] Упаковка в нативное офлайн-приложение на **Tauri (Rust)** + локальный снапшот SQLite.
- [ ] Экспорт инструментальных сборок в форматы **GTC (Generic Tool Catalog)**, FreeCAD `.fctb`, JSON/CSV для CAM.
- [ ] Импорт пользовательских прайс-листов и складских остатков цеха (CSV/Excel) для подбора «из того, что есть на складе».
