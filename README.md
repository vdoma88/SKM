# ISO Tooling Selector (SKM)

Бренд-нейтральное веб-приложение и API для подбора твердосплавных пластин (СМП) и корпусного инструмента для токарной, фрезерной и осевой обработки. Построено на стандартах **ISO 13399**, **ISO 1832**, **ISO 513**, физическом ядре **Кинцле** и браузерном **3D CAD-вьюере**.

## Онлайн-демо (GitHub Pages)
После включения GitHub Pages приложение доступно по прямой ссылке для коллег без установки ПО:
`https://vdoma88.github.io/SKM/`

## Возможности v0.5
- **Инженерный GUI с 4 вкладками:** *Подбор и режимы*, *3D-Просмотр и STEP/STL*, *Сравнение «бок о бок»*, *Наладки и экспорт*. Поддержка светлой/тёмной темы, мм/дюймов, мобильных экранов и шаринга расчётов по URL (**🔗 Поделиться**).
- **Визуальный ISO 1832 декодер:** мгновенный разбор кодов (`CNMG`, `CNGA`, `WNMG`, `DNMG`, `VNMG`, `SNMG`, `CCMT`, `DCMT`, `APKT`, `SEKT`, `RDMT`, `WCMX`, `SPMG`) и генерация ключа гнезда (`seat_pocket_signature`).
- **Физика Кинцле + жёсткость оправки:** RPM, $v_f$, $h_m$ (с радиальным утонением), $F_c$, MRR, мощность $P_c$, момент $M_c$, теоретическая шероховатость $R_a$ (включая Wiper) и прогиб оправки $\delta$ ($L/D$).
- **3D-вьюер ISO 1832 и CAD:** процедурная 3D-геометрия пластин с PBR-покрытиями, экспорт `.stl` и локальный импорт `.step` / `.stp` / `.iges` / `.brep` / `.stl` через OpenCASCADE WASM.
- **Сравнение и экспорт наладок:** матрица сравнения до 3 пластин, сохранение своих станков и наладок, выгрузка в **Excel (CSV)**, **JSON**, **FreeCAD `.fctb`** и печать PDF-карты наладки.

## Запуск с PostgreSQL + FastAPI (Docker Compose)

```bash
docker compose up --build
```
- **GUI:** http://localhost:8000/
- **OpenAPI / Swagger:** http://localhost:8000/docs
