# ISO Tooling Selector Studio (SKM v1.1)

Бренд-нейтральная инженерная система подбора твердосплавных пластин (СМП) и корпусного инструмента для токарной, фрезерной, сверлильной и канавочно-резьбовой обработки. Построена на стандартах **ISO 13399**, **ISO 1832**, **ISO 513**, физическом ядре **Кинцле**, модели стойкости **Тейлора** и браузерном **3D CAD-вьюере**.

## Онлайн-демо (GitHub Pages)
Приложение работает автономно прямо в браузере (и устанавливается как **PWA** для офлайн-работы в цеху):
`https://vdoma88.github.io/SKM/`

## Возможности v1.1
- **5 инженерных вкладок:** *Подбор и режимы*, *3D-Просмотр и STEP/STL*, *Сравнение «бок о бок»*, *Наладки и CAM*, *Склад цеха*. Светлая/тёмная тема, `мм / in`, шаринг расчёта по URL (**🔗 Поделиться**).
- **Расширенный каталог (21 пластина, 16 корпусов, 12 подгрупп ISO 513):** точение (`CNMG`, `WNMG`, `TNMG`, `DNMG`, `VNMG`, `SNMG`, `CCMT`, `CCGT`, `DCMT`, `CNGA`), фрезерование (`APKT`, `SEKT`, `RDMT`), проработанный осевой инструмент (11 позиций: U-свёрла `WCMX`/`WCMT`/`SPMG`/`SOMT`, сменные коронки `MOD-DRL`, монолитные ЦТ-свёрла `SC-DRL` с внутренним СОЖ до 8xD), канавки и резьба (`MGMN 300`, `16ER AG60`).
- **Физика Кинцле + жёсткость оправки + экономика Тейлора:** RPM, $v_f$, $h_m$, $F_c$, MRR, $P_c$, $M_c$, шероховатость $R_a$, прогиб оправки $\delta$ ($L/D$), стойкость режущей кромки (мин), деталей на кромку и себестоимость детали (`₽/дет`).
- **Склад цеха (`app/inventory.py`):** 14 стартовых позиций, импорт/экспорт CSV (Excel), редактирование остатков и цен, фильтр подбора «Только в наличии на складе».
- **3D-вьюер ISO 1832 и STEP/IGES/STL:** параметрическая 3D-геометрия с PBR-покрытиями, экспорт `.stl` и клиентский импорт `.step`/`.iges`/`.brep`/`.stl` (OpenCASCADE WASM).
- **Экспорт в CAM (`app/cam_export.py`):** **ISO 13399 GTC v2.0**, **Autodesk Fusion 360 (`.tools`)**, **FreeCAD (`.fctb`)**, Excel CSV, JSON и печать карты наладки.


- **OpenAPI / Swagger:** http://localhost:8000/docs
